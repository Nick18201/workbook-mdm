# Workbook - Chapitre 7 : Le Champ des Possibles 🔭

*Ce chapitre marque le passage du rêve à la réalité.*

---

## 1. Concept
*   **Moment** : Généré suite à la **Séance 6** (après le retour des enquêtes terrain).
*   **Objectif** : Structurer l'exploration et valider le choix final.
*   **Mots-clés** : Ouverture, Réalisme, Choix.

---

## 2. Structure du PDF (Rendu Final)

### Page 1 : L'Entonnoir des Idées (Exploration)
*   **Visuel** : Un graphique en entonnoir (Funnel) ou une liste épurée.
*   **Contenu** :
    *   **Phase Divergente** : "J'ai exploré ces pistes : `[Liste Pistes]`."
    *   **Le filtre** : "J'ai écarté `[Piste écartée]` car `[Raison]`."
    *   **La pépite** : "La piste qui a retenu mon attention : `[Piste Plan A]`."

### Page 2 : Retour du Terrain (Enquêtes)
*   **Concept** : Fiche de synthèse "Reality Check".
*   **Contenu** :
    *   **Le Mythe** : "Je croyais que... `[Idée reçue]`."
    *   **La Réalité** : "J'ai découvert que... `[Réalité terrain]`."
    *   **L'Avis d'Expert** : "Citation clé d'un professionnel rencontré : `[Citation]`."
    *   **Note de Viabilité** : `[X]/5` (basée sur le ressenti post-enquête).

### Page 3 : Matrice de Faisabilité (Le Crash Test)
*   **Visuel** : Tableau avec indicateurs type "Feux Tricolores" (Rond Rouge/Orange/Vert).
*   **Les Critères** :
    1.  **Finances** : Vert (Finançable) / Orange (Juste) / Rouge (Risqué).
    2.  **Temps/Organisation** : Vert (Compatible) / Rouge (Impact vie pro/perso lourd).
    3.  **Compétences** : Vert (Acquises) / Orange (Formation nécessaire).
    4.  **Marché** : Vert (Porteur) / Orange (Bouché).
*   **Verdict** : "`[GO / NO GO / SLOW GO]`".

### Page 4 : Mon Choix Final (Plan A & B)
*   **Visuel** : Mise en avant solennelle.
*   **Plan A (L'Étoile)** : "Je décide de m'engager vers : `[Projet A]`."
*   **Plan B (Le Filet)** : "Si besoin, je garde en réserve : `[Projet B]`."

---

## 3. Formulaire de Collecte (Source de données)

**Partie 1 : Le Bilan des Pistes**
*   "Quelles sont les 3 pistes principales que vous avez explorées ?"
*   "Quelle est celle que vous retenez aujourd'hui comme Plan A ?"

**Partie 2 : Le Retour d'Enquête**
*   "Quelle a été votre plus grande surprise (positive ou négative) en parlant avec des pros ?"
*   "Une phrase marquante entendue ?"

**Partie 3 : Le Scoring (Matrice)**
*   "Sur une échelle de 1 à 3 (Rouge/Orange/Vert), évaluez la faisabilité financière de votre Plan A."
*   "Idem pour l'équilibre vie pro/perso."
*   "Idem pour l'accès au marché."

---

## 4. Instructions Techniques

*   **Feux Tricolores** :
    *   Utiliser des émojis (🔴 🟠 🟢) dans le PDF si le générateur ne gère pas les images conditionnelles complexes. C'est simple et efficace visuellement.
*   **Funnel** :
    *   Représenter l'entonnoir par une liste indentée :
        *   Toutes les idées (Bullet points gris)
            *   Les pistes sérieuses (Bullet points noirs)
                *   **LE CHOIX (Gras/Encadré)**
