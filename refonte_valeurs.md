Chapitre 5 · VALEURS
Ce workbook vous aide à identifier ce qui compte profondément pour vous dans votre vie professionnelle.
Les valeurs ne sont pas seulement des idées abstraites. Elles se repèrent dans les situations où vous vous sentez :
motivé(e) ;
fier(e) ;
utile ;
libre ;
reconnu(e) ;
en confiance ;
mais aussi frustré(e), en colère, vidé(e), empêché(e) ou en conflit intérieur.
L’objectif n’est pas de choisir les valeurs qui semblent les plus “belles” ou les plus attendues, mais d’identifier celles qui influencent réellement vos choix, votre énergie et votre rapport au travail.

3. Mes choix difficiles
Les valeurs apparaissent souvent dans les choix difficiles, car choisir implique parfois de renoncer à quelque chose d’important.
Repensez à deux situations où vous avez dû choisir entre deux options.
Exemples :
rester ou partir ;
accepter ou refuser une opportunité ;
sécuriser ou prendre un risque ;
dire oui ou poser une limite ;
chercher la reconnaissance ou préserver l’équilibre ;
aider les autres ou prendre soin de soi ;
suivre le cadre ou faire à sa façon.

Mes 5 valeurs prioritaires

Mes 3 valeurs non négociables
Parmi ces 5 valeurs, choisissez les 3 qui semblent les plus essentielles pour vous.
Une valeur non négociable est une valeur qui, si elle est durablement absente de votre travail, risque d’entraîner une perte de motivation, d’énergie ou de sens.

7. Traduire mes valeurs en conditions de travail
Une valeur devient vraiment utile lorsqu’on la traduit en critères concrets.
Complétez les phrases suivantes.
Pour respecter mes valeurs, j’ai besoin d’un environnement où…
Exemples :
je peux organiser mon travail avec autonomie ;
les relations sont respectueuses ;
les objectifs sont clairs ;
je peux apprendre régulièrement ;
je me sens utile ;
mon travail est reconnu ;
je peux prendre des initiatives ;
le rythme est soutenable.
Mes réponses :
Pour respecter mes valeurs, j’ai besoin d’éviter les environnements où…
Exemples :
tout est contrôlé ;
les priorités changent sans cesse ;
il y a peu de reconnaissance ;
les relations sont froides ou compétitives ;
le travail manque de sens ;
la pression est permanente ;
les règles sont rigides ;
il n’y a pas de perspective d’évolution.
