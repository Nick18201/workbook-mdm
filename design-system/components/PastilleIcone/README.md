# PastilleIcone

Icône Material Symbols Outlined dans un disque : elle ouvre un élément de liste ou une étape.

**Fournir** : le nom de l'icône Material Symbols (style Outlined) et le fond sur lequel la pastille se pose.

**Règles**
- Disque de 48 à 56 px, `radius-full`. Sur une carte pastel : `surface-card` à 70 %. Sur `surface` ou `surface-alt` : un pastel.
- Icône de 24 à 30 px en `brand-blue` (ou `ink` sur un pastel).
- Toujours décorative (`aria-hidden`) : le texte voisin porte le sens.

**Ne pas faire** : d'icône pleine (Filled), d'émoji, d'icône seule sans texte.
