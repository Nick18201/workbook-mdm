# Venn

Diagramme de Venn à trois cercles translucides, dont l'intersection est en bleu plein : la méthode qui croise trois regards.

**Fournir** : trois libellés (titre et précision) et le libellé de l'intersection.

**Règles**
- Cercles : `brand-coral` à 20 %, `pastel-jasmine` à 70 %, `brand-blue` à 15 % ; intersection des trois en `brand-blue` plein, libellé blanc.
- Libellés en HTML (pas en texte SVG) : titre DM Sans 800, précision Manrope 12 px `ink-muted`, jamais sous 11 px.
- Le contraste se vérifie sur la couleur mélangée (cercle sur le fond), pas sur le token seul.

**Ne pas faire** : de cercles opaques, plus de trois cercles.
