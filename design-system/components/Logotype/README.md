# Logotype

Le logotype est typographique : « marge / de manœuvre » en Manrope 800, minuscules, sur deux lignes, souligné d'un trait épais. Il n'existe pas de fichier logo.

**Fournir** : rien ; choisir la forme (en-tête ou signature).

**Règles**
- En-tête : style `logotype` (20 px, interligne 0,85, -0,05 em), `ink`, trait `ink` de 96 × 4 px, 8 px dessous.
- Signature géante (pied de page, couverture) : sur une ligne, la largeur du conteneur, terminée par un point `brand-coral` d'environ 0,17 em ; elle reste entière, avec de l'air dessous.
- Sur un fond bleu, le logotype et le trait passent en blanc.

**Ne pas faire** : de majuscules, d'autre police, de couleur sur le texte, de signature rognée au bord de la page.
