# Tampon

Tampon « Validé en séance » : il signe un livrable validé avec la personne qui accompagne.

**Fournir** : le libellé (« Validé en séance » par défaut).

**Règles**
- Bordure `trait-tampon` en `brand-coral-strong`, `radius-tampon`, PT Mono 12 px majuscules, interlettrage 0,1 em, texte `brand-coral-strong`, icône coche.
- Rotation `rotation-tampon`. Posé sur le post-it du livrable.

**Ne pas faire** : un tampon en `brand-coral` (trop pâle), ailleurs que sur un livrable.
