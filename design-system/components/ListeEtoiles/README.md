# ListeEtoiles

Liste à puces étoile à 4 branches, en `brand-coral-strong` : la liste des exercices et protocoles d'un carnet.

**Fournir** : 3 à 6 éléments courts, avec un `sourcil` au-dessus (« Exercices & protocoles »).

**Règles**
- Étoile de 14 px en `brand-coral-strong`, `space-3` entre l'étoile et le texte, et entre les éléments.
- Texte `corps` en `ink`, interligne 1,375.
- Tracé de l'étoile : `M8 0 C 8.6 5.2, 10.8 7.4, 16 8 C 10.8 8.6, 8.6 10.8, 8 16 C 7.4 10.8, 5.2 8.6, 0 8 C 5.2 7.4, 7.4 5.2, 8 0 Z` (viewBox 0 0 16 16).

**Ne pas faire** : de puces rondes ou de tirets à la place, d'étoile en `brand-coral` (trop pâle en petit).
