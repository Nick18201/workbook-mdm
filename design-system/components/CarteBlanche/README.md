# CarteBlanche

Carte blanche bordée d'un filet : pour un résultat, un fait sourcé, une page posée sur un fond lin.

**Fournir** : un sourcil, un titre, un texte ; éventuellement une photo à fond perdu en haut.

**Règles**
- Fond `surface-card`, bordure 1 px `line`, `radius-carte`.
- Ombre `shadow-bento` seulement pour la carte mise en avant.
- Photo à fond perdu : elle touche les bords de la carte, sans marge.

**Ne pas faire** : une carte blanche sur `surface-card` sans bordure, une ombre sur toutes les cartes.
